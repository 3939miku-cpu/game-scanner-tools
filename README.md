## 🚀 使用方法

1. 下载对应的 zip 文件
2. 解压到任意文件夹
3. 安装依赖：`pip install -r requirements.txt`
4. 运行：双击 `一键运行.bat` 或 `python main.py`

---

## ⚠️ 注意事项

- 游戏工具需要 1920x1080 窗口模式
- 需要模板图片才能正常识别
- 扫描时不要操作游戏
